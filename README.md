# larry_v3_pid_lfr


## overview

Larry v3 is a PID-controlled line following robot built primarily from scrap aluminum strips, paper boards and off-the-shelf electronic parts.

The objective of the project was to develop a functional closed-loop line following robot while exploring PID control, PWM and embedded control systems implementation.

Although Larry successfully completes the track(most of the time), several issues remain including jitter during tracking, unoptimised motor voltage leading to slow track completion times, and a lack of sensor calibration functionality.

This repository tracks and documents the current state of larry and outlines lackings and consequent future improvements.
